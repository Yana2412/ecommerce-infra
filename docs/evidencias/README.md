# Evidencias

Cada evidencia debe incluir: número y nombre, fecha, integrante responsable,
comando o acción realizada, captura o salida obtenida, explicación del resultado,
y relación con un concepto de Sistemas Operativos.

No se aceptan capturas sin explicación ni comandos visibles únicamente como imagen.
